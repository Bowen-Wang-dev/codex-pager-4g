# 📟 Codex Pager 4G

**一款复古传呼机风格的独立无线终端，用于 AI Agent 通知、额度监控和人工权限审批。**

> AI 负责执行，传呼机负责通知，人类保留最终决定权。

[English README](README.md)

## 项目简介

Codex Pager 4G 是一个开源软硬件项目，旨在将经典传呼机的设计理念带入 AI Agent 时代。

本项目计划采用 ESP32 系列微控制器，结合复古传呼机外壳、彩色显示屏、实体按键、蜂鸣器及无线网络，实现一台可以随身携带的 AI Agent 控制终端。

设备主要面向 Codex，同时保留未来接入其他 AI Agent 的可能性。

用户无需一直守在电脑旁，也不必反复打开应用程序，即可查看 Agent 状态、接收事件通知，并对权限请求作出人工决定。

**项目状态：** 概念设计与规划阶段

**立项日期：** 2026 年 10 月 24 日

## 主要功能（计划实现）

### 📊 实时额度监控

- 显示 5 小时额度及每周额度剩余情况。
- 显示下次额度重置时间。
- 提供额度恢复倒计时。
- 无需进入电脑或手机应用即可查看状态。
- 在数据可用时自动同步最新状态。

### 🔔 复古传呼机通知

采用经典的三声 BB 机提示音，在重要事件发生时主动提醒用户。

| 事件 | 表情 | 提醒方式 |
|---|---|---|
| 额度耗尽 | 😐🤲 | 三声蜂鸣 |
| 额度恢复 | 😋 | 三声蜂鸣 |
| 请求人工审批 | 🥺 | 三声蜂鸣 |
| 权限被拒绝 | 😭 | 屏幕反馈 |
| 任务完成 | ✅ | 可配置通知 |
| Agent 异常 | ⚠️ | 警告提示 |

后续版本将考虑支持自定义通知声音及表情。

### ✅ 实体按键权限审批

设备计划支持 Human-in-the-loop（人在回路）工作模式。

用户可通过实体按键：

- 查看等待处理的权限请求。
- 阅读 Agent 请求执行的命令或操作。
- 手动批准或拒绝请求。
- 查看操作处理结果。

对于内容过长或具有较高风险的请求，设备应提示用户返回电脑进行详细审查。

**设备不会自动批准权限请求，所有审批均须由用户明确确认。**

### 📡 Wi-Fi 与 4G 无线连接

设备计划支持两种连接方式：

**Wi-Fi 模式**

利用 ESP32 内置 Wi-Fi 功能，在家庭、办公室及其他可用网络环境下连接服务器。

**4G LTE 模式**

集成支持 SIM 卡插入的 4G LTE Modem，实现独立蜂窝网络连接。

设计目标是让设备即使离开电脑和本地 Wi-Fi 网络，也能够接收 Agent 通知并同步状态。

具体通信模块、网络兼容性及功耗表现将在硬件开发阶段测试确定。

### 🎨 复古传呼机外观

- 经典 1990 年代传呼机设计风格。
- 定制 3D 打印外壳。
- 支持彩色 Emoji 图形的显示屏。
- 实体导航、确认及拒绝按钮。
- 复古 BB 机三声蜂鸣器。
- 内置可充电电池。
- 适合口袋携带的便携式设计。

配套服务端计划负责 Agent 接口集成、状态同步、通知传输，以及经过身份验证的权限审批交互。

## 设计原则

1. **人类保留控制权：** AI 可以自主执行任务，但需要审批的操作必须得到明确授权。
2. **信息一目了然：** 拿起设备即可查看重要状态。
3. **只在必要时打扰用户：** 减少无意义通知。
4. **便携且相对独立：** 不必始终处于电脑旁。
5. **安全优先：** 验证请求身份、防止过期审批和实体按键误触。
6. **复古外观与现代技术结合：** 保留传呼机的经典设计，同时满足 AI Agent 的实际交互需求。

## 项目理念

传统传呼机使人们无需守在电话旁，也能及时得知有人需要联系自己。

Codex Pager 4G 希望将同样的理念应用于 AI Agent：

**让 AI 自己工作，在需要人类注意或授权时主动发出通知。**
